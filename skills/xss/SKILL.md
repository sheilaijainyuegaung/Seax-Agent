# XSS（决策）

## 前置
输入出现在 HTML / 属性 / 脚本段。先定位上下文，再判断是否可能执行。

## 决策
1. 仅原文回显、被编码或落在纯文本 → 记 XSSr，标「反射待确认」，不要当漏洞入库
2. 进入可执行上下文且未被有效编码 → 才能进入 verify
3. 本环境没有浏览器观察时：最高记 info「反射待确认」，写明缺浏览器证据

## 验证纪律
- 扫描器告警 ≠ XSS
- 存储型必须证明再次打开页面仍出现，且有请求/响应证据
- 不要用弹窗演示当唯一证据
