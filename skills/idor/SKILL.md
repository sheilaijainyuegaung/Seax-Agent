# 越权 / IDOR（决策）

## 前置
接口带对象标识（数字 ID、订单号、用户名）。需要至少一种身份或「去会话」对照。

## 决策
1. 同一身份改对象 ID：别人的资源也能读 → 水平越权
2. 低权限打高权限对象 → 垂直越权
3. 去 Cookie / 换无效会话仍返回业务数据 → 未授权
4. 仅 401/403 且无数据差异 → miss

## 验证纪律
- 对照请求各绑一条证据
- 只读证明即可，不要改别人的业务数据
- 返回：命中? / 边界（水平/垂直/未授权） / 衍生
