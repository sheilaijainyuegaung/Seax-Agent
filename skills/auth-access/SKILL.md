# 认证 / 未授权（决策）

## 前置
给定资产上的登录口、带 Cookie 的接口、声明「需登录」的页面。

## 决策
1. 同一请求「带会话 / 去会话」对照：去会话仍返回业务数据 → 未授权
2. 登录口：只对给定入口试常见默认口令；成功必须有 302/业务页证据
3. 每次登录先取页面里的 CSRF / token，不要用过期表单
4. JWT/Session 只做明显缺陷观察（未校验、算法混乱的证据），不做爆破全家桶

## 验证纪律
- 写入类（改密、注册）先问用户
- 弱口令命中后立刻 record_finding，不要继续扫其他账号
- 返回：命中? / 类型 / 衍生
