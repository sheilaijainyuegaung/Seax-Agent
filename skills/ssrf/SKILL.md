# SSRF（决策）

## 前置
参数语义像「去拉一个地址」：回调、头像、导入、预览。只在给定资产上证明。

## 决策
1. 换一个明显不可达/可达的对照地址，看耗时、错误词、状态是否随地址变
2. 稳定随地址变化 → 记「服务端发起了请求」为 hit（证明存在）
3. 无差异 → skip

## 验证纪律
- 不要把 SSRF 当成内网扫描入口，不扫未授权网段
- 证明「会对外请求用户输入」即可，不要读云元数据、不要打旁站
- 返回：命中? / 依据（时差或错误词） / 衍生
