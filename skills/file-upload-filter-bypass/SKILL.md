description: 测试文件上传功能的类型限制，验证可否上传可执行脚本
when: 文件上传, webshell, 上传绕过, 过滤绕过
modes: pentest, redteam
x-source-session: 20261101_161427_f5102d_pentest
---

1. 识别文件上传功能点，确认允许的文件类型限制（前端/后端）。
2. 上传对照文件（如 .jpg 图片），确认正常文件上传成功路径和存储位置。
3. 上传测试脚本文件（.php/.jsp/.asp 等）：
   - 上传无害探针文件（如 echo 标记），验证后端是否做了扩展名过滤。
   - 如果被拒绝，尝试扩展名绕过：大小写混合（.PhP）、双扩展名（.php.jpg）、空格/点号截断（.php%00.jpg、.php.）。
   - 尝试 Content-Type 欺骗（前端校验可直接绕过，关注后端是否仅依赖 MIME type）。
4. 如果上传成功，检查文件存储路径（响应中通常暴露目录），尝试直接访问确认是否可执行。
5. 注意：本次仅验证过滤缺失，上传无害探针，避免上传真正 webshell 造成不必要的危害。
6. 修复建议：服务端扩展名白名单 + Content-Type + 文件魔数三重校验；随机化存储名；上传目录禁止脚本执行。
